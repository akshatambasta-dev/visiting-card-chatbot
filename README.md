> Replicated digital visiting card and consulting portfolio for **Deepak Jain** (The Master Strategy Hub & Buddhi Framework), augmented with an interactive, responsive **Buddhi AI Chatbot Assistant**.

---

## 🌟 Overview

This project is a high-fidelity replica of [visiting-card-deepak-jain.onrender.com](https://visiting-card-deepak-jain.onrender.com/) featuring:
- **40+ Years of Multi-Sector Experience**: Chronicling Hindustan Instruments (1968), Computer Components (1986), consultancy since 2009, and the roadmap to a 2030 IPO.
- **The Buddhi Framework**: Practical business rules including *Rule No. 78 ("Overthinking kills deals. Simple execution closes them")* and *Rule No. 80*.
- **4 Consulting Pillars**: Finance (debt restructuring, cash flow), Marketing (positioning, in-film placement), Renewables (solar & agrivoltaics), and IT/AI delivery.
- **The 8 MW Agrivoltaics Power Plant**: The flagship dual-purpose clean energy + farming venture.
- **Publishing & Thought Leadership**: The upcoming book *Breaking Walls, Building Legacy* (10 legendary 20th-century Indian women) and commentary across *Mint*, *Financial Times*, and *Free Press Journal*.
- **Interactive Buddhi AI Chatbot**: A custom floating assistant matching the editorial visual design, supporting instant smart querying, consultation booking guidance (₹501/- first session), theme awareness, sound effects, and direct WhatsApp / Email routing.

## 🤖 Chatbot Features

1. **Brand Aesthetic Alignment**:
   - Styled with the site's signature cream/ivory (`#F7F1E4`), navy (`#0F1D33`), and gold (`#C79B44`) palette.
   - Synchronizes automatically with the site's dark/light mode toggle.
2. **Instant Semantic Knowledge Engine**:
   - Responds to inquiries on consulting services, Buddhi framework rules, case studies (e.g. ₹60L in-film financing for Tanuj), the 8 MW solar project, upcoming Gen Z mentoring cohorts, and internships.
3. **Smart Conversion CTAs**:
   - Embedded direct action buttons to start a WhatsApp conversation or send an email to `ceo4wisdom@gmail.com`.
4. **Interactive UX**:
   - Floating circular launcher with live pulse indicator.
   - One-tap quick suggestion pills for common questions.
   - Realistic typing bounce indicator.
   - Subtle Web Audio API chime on response (can be toggled on/off).
   - Session storage preservation across page interactions.

## 🚀 Quick Start (Local Preview)

Since all assets and images are self-contained, you can run this with any static web server:

### Using Python:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

### Using Node.js (npx):
```bash
npx serve .
```

## 🌐 Deploy to GitHub Pages

1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/akshatambasta-dev/visiting-card-chatbot.git
   git branch -M main
   git push -u origin main
   ```
2. In your repository on GitHub:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` / `root` and click **Save**.
3. Your site with the active AI chatbot will be live in seconds!
